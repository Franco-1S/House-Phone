HAUSTELEFON for Windows (x64)
=============================

English
-------
Install:    double-click Install.cmd  (no admin rights needed)
            -> installs to %LOCALAPPDATA%\Programs\Haustelefon,
               creates Desktop and Start menu shortcuts and starts the app.
Portable:   or just run app\haustelefon.exe directly.
Uninstall:  double-click Uninstall.cmd (keeps settings, contacts, history).

Closing the window keeps Haustelefon running in the notification area
(bottom right, next to the clock) so you stay reachable. Right-click the
icon -> Quit to exit. "Start with Windows" is in Settings -> PC.

Windows SmartScreen may warn because the app is not code-signed:
"More info" -> "Run anyway".

You need a Haustelefon server (Asterisk) in your network - see the
project page on GitHub. Licence: MIT.


Deutsch
-------
Installieren:  Install.cmd doppelklicken (keine Adminrechte noetig)
               -> installiert nach %LOCALAPPDATA%\Programs\Haustelefon,
                  legt Verknuepfungen auf Desktop und im Startmenue an
                  und startet die App.
Portabel:      oder einfach app\haustelefon.exe direkt starten.
Entfernen:     Uninstall.cmd doppelklicken (Einstellungen, Kontakte und
               Anrufliste bleiben erhalten).

Schliesst du das Fenster, laeuft Haustelefon im Infobereich weiter (unten
rechts neben der Uhr) - du bleibst erreichbar. Beenden: Rechtsklick auf das
Symbol -> Beenden. "Mit Windows starten" unter Einstellungen -> PC.

Windows SmartScreen warnt eventuell, weil die App nicht signiert ist:
"Weitere Informationen" -> "Trotzdem ausfuehren".

Du brauchst einen Haustelefon-Server (Asterisk) im Netz - siehe
Projektseite auf GitHub. Lizenz: MIT.
